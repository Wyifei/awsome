# 统一身份认证平台 - 需求文档

## 概述

为电动自行车制造企业构建基于 OIDC 协议的统一身份认证平台，服务于官网、移动 APP 等多端应用。

## 用户故事

### 1. 用户注册

#### 1.1 邮箱注册
作为新用户，我希望能够使用邮箱注册账号，以便访问平台服务。

**验收标准：**
- 1.1.1 用户可以输入邮箱、密码和昵称进行注册
- 1.1.2 密码必须满足强度要求（8位以上，包含大小写字母和数字）
- 1.1.3 邮箱格式必须有效
- 1.1.4 已注册的邮箱不能重复注册
- 1.1.5 注册成功后发送验证码邮件
- 1.1.6 用户在 Cognito 和本地数据库同时创建

#### 1.2 邮箱验证
作为注册用户，我希望能够验证我的邮箱，以便激活账号。

**验收标准：**
- 1.2.1 用户收到包含6位数字验证码的邮件
- 1.2.2 验证码有效期为15分钟
- 1.2.3 验证成功后账号状态变为 ACTIVE
- 1.2.4 验证成功后发送欢迎邮件
- 1.2.5 可以重新发送验证码
- 1.2.6 验证成功后同步更新 Cognito 的 email_verified 状态

### 2. 用户登录

#### 2.1 密码登录
作为已注册用户，我希望能够使用邮箱和密码登录，以便访问我的账号。

**验收标准：**
- 2.1.1 用户可以输入邮箱和密码进行登录
- 2.1.2 登录成功后获取 JWT Token（Access Token、ID Token、Refresh Token）
- 2.1.3 未验证邮箱的用户无法登录
- 2.1.4 密码错误时显示友好的错误提示
- 2.1.5 登录状态通过 Cognito 管理

#### 2.2 登出
作为已登录用户，我希望能够安全登出，以便保护我的账号安全。

**验收标准：**
- 2.2.1 用户可以主动登出
- 2.2.2 登出后清除本地 Token
- 2.2.3 登出后跳转到登录页面

### 3. 密码管理

#### 3.1 忘记密码
作为用户，我希望能够在忘记密码时重置密码，以便恢复账号访问。

**验收标准：**
- 3.1.1 用户可以通过邮箱请求密码重置
- 3.1.2 系统发送包含验证码的重置邮件
- 3.1.3 验证码有效期为15分钟
- 3.1.4 验证码正确后可以设置新密码
- 3.1.5 新密码必须满足强度要求

#### 3.2 修改密码
作为已登录用户，我希望能够修改密码，以便提高账号安全性。

**验收标准：**
- 3.2.1 用户需要输入当前密码和新密码
- 3.2.2 当前密码验证正确后才能修改
- 3.2.3 新密码必须满足强度要求
- 3.2.4 修改成功后发送密码变更通知邮件

### 4. 用户资料管理

#### 4.1 查看资料
作为已登录用户，我希望能够查看我的个人资料，以便了解账号信息。

**验收标准：**
- 4.1.1 用户可以查看昵称、性别、生日、地址等信息
- 4.1.2 用户可以查看头像
- 4.1.3 用户可以查看邮箱验证状态

#### 4.2 更新资料
作为已登录用户，我希望能够更新我的个人资料，以便保持信息准确。

**验收标准：**
- 4.2.1 用户可以修改昵称、性别、生日、地址
- 4.2.2 修改成功后发送资料变更通知邮件
- 4.2.3 资料更新后立即生效

#### 4.3 头像管理
作为已登录用户，我希望能够上传和更新头像，以便个性化我的账号。

**验收标准：**
- 4.3.1 支持上传 JPG、PNG 格式图片
- 4.3.2 图片大小限制为 2MB
- 4.3.3 头像存储在数据库中（Base64 编码）
- 4.3.4 可以删除头像恢复默认

### 5. 账号管理

#### 5.1 获取身份信息
作为已登录用户，我希望能够获取我的身份信息，以便确认账号状态。

**验收标准：**
- 5.1.1 返回用户 ID、用户名、邮箱、手机号
- 5.1.2 返回邮箱验证状态、手机验证状态
- 5.1.3 返回账号状态（ACTIVE/INACTIVE/SUSPENDED）
- 5.1.4 返回账号创建时间和更新时间

#### 5.2 账号注销
作为已登录用户，我希望能够注销我的账号，以便删除我的所有数据。

**验收标准：**
- 5.2.1 用户需要通过邮箱验证码确认注销
- 5.2.2 验证码有效期为15分钟
- 5.2.3 注销后删除 Cognito 用户
- 5.2.4 注销后删除本地数据库记录
- 5.2.5 注销后发送账号删除通知邮件
- 5.2.6 注销操作不可逆

### 6. 邮件通知

#### 6.1 验证码邮件
作为系统，我需要发送验证码邮件，以便用户完成验证操作。

**验收标准：**
- 6.1.1 支持邮箱验证、密码重置、账号注销三种验证码类型
- 6.1.2 邮件包含6位数字验证码
- 6.1.3 邮件包含验证码有效期提示
- 6.1.4 使用 Amazon SES 发送邮件

#### 6.2 通知邮件
作为系统，我需要发送通知邮件，以便用户了解账号变更。

**验收标准：**
- 6.2.1 注册成功后发送欢迎邮件
- 6.2.2 密码修改后发送变更通知
- 6.2.3 资料修改后发送变更通知
- 6.2.4 账号删除后发送确认通知

## 非功能性需求

### 7. 安全性

- 7.1 所有 API 通过 HTTPS 传输
- 7.2 敏感数据（密码）不在日志中记录
- 7.3 JWT Token 有效期：Access Token 1小时，Refresh Token 30天
- 7.4 验证码有效期15分钟，使用后立即失效
- 7.5 密码存储使用 Cognito 托管（SRP 协议）

### 8. 可用性

- 8.1 服务部署在多可用区
- 8.2 数据库使用 Aurora 多副本
- 8.3 前端通过 CloudFront CDN 分发

### 9. 可观测性

- 9.1 所有服务输出结构化 JSON 日志
- 9.2 日志包含 trace_id 支持分布式追踪
- 9.3 暴露 Prometheus 指标端点
- 9.4 记录业务指标（注册数、登录数等）

### 10. 性能

- 10.1 API 响应时间 P95 < 500ms
- 10.2 支持水平扩展（HPA）
- 10.3 数据库连接池优化
